As a real estate listing agent, I want to receive validation messages when required property information is missing or invalid, so that I can correct errors before submitting a listing.

Source: REQ-001 / US-02; OBS-01 and OBS-02 are simulated, not verified interviews.
Priority: High. Effort: Medium.
Proposed branch: `feature/req-001-listing-validation`
Requested labels: enhancement, validation, ui.
Milestone: [Week 8 MVP](https://github.com/byteboss22/cis3610-capstone-beacon/milestone/1); scope remains provisional.

```gherkin
Scenario: Successful listing validation and submission
  Given address and description are present and price is a positive number
  When the agent submits the listing
  Then validation succeeds and one Pending Review item is created
  And the listing remains unpublished until authorized approval

Scenario: Missing listing price prevents submission
  Given address and description are present but price is blank
  When the agent submits the listing
  Then a price-required message appears beside price
  And submission is prevented and entered values remain
```
